# Yahoo! News Scraper

キーワード検索によってヒットしたYahoo!ニュースの記事情報（タイトル・概要・配信元/日時・URL）を自動収集し、Excelファイル（`.xlsx`）として出力するPythonスクレイピングツールです。

## 主な機能・特徴
- **動的ページネーション対応**：「もっと見る」ボタンの自動クリックと追加読み込み待機により、最大150件の記事を一括取得します。
- **データクレンジング・整形**：取得したデータを項目ごとに分離し、Pandasを用いて見やすいExcel形式で出力します。
- **堅牢なエラー処理**：検索キーワードのURLエンコードや、Windowsファイル名禁則文字の自動置換（サニタイズ）、例外発生時の安全なブラウザ終了処理を実装しています。

## 使用技術
- Python 3
- Playwright（ブラウザ自動操作・動的コンテンツ取得）
- Pandas / openpyxl（データ整形・Excel出力）

## セットアップ手順
スクリプトを保存したディレクトリでターミナルを開き、必要なライブラリとブラウザエンジンをインストールしてください。

```bash
pip install playwright pandas openpyxl
playwright install chromium
