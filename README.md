# Yahoo_News_Scraper
YahooNEWSのスクレイピングツールです。実行し、検索ワードを入力していただければヒットした記事のタイトル、概要、配信元と日時、URLを最大で150件分まとめ、1つのExcelファイルにて出力します。使用技術（Python / Playwright / Pandas）ターミナルにて保存先のフォルダを参照し、{py yahoo_news_scraper.py}を実行すると、「"検索したいキーワード：」と出るため、そこに検索ワードを入力し、エンターキーをクリックして下さい。数秒から数十秒後にエクセルファイルが同ファイルに保存されます。ファイル名はyahoo_search_検索ワード.xlsxとなっています。
